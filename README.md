# Teledetección: informe final (UDELAR)

Informe final del curso de **Teledetección**, Licenciatura en Geología, Facultad de Ciencias (UDELAR), 2022.

📄 [`Rubens_Merlino_Informe_Final.pdf`](Rubens_Merlino_Informe_Final.pdf)

## Resumen
Procesamiento de imágenes ópticas de las misiones **Landsat** (NASA) y **Sentinel** (ESA) mediante índices, combinaciones de bandas, filtros y clasificación.

- **Área de estudio**: entre los departamentos de Lavalleja, Treinta y Tres y Rocha (Uruguay), sector NE del lineamiento Santa Lucía – Aiguá – Merín (SaLAM), con afloramientos de las formaciones Arequita y Valle Chico.
- **Flujo de trabajo**: corrección atmosférica y geométrica, realces para definir clases, clasificación no supervisada y evaluación con matriz de confusión.
